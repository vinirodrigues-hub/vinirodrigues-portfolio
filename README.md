# Portfólio — Vinícius Silva Rodrigues

Portfólio pessoal desenvolvido para apresentar minha trajetória acadêmica, conhecimentos em tecnologia, projetos desenvolvidos e informações de contato.

O projeto foi desenvolvido como parte dos meus estudos em Engenharia de Software, com foco na prática de desenvolvimento Front-end e na construção de interfaces web.

**Acesse o portfólio:** [vinirodrigues-hub.github.io/vinirodrigues-portfolio](https://vinirodrigues-hub.github.io/vinirodrigues-portfolio/)

---

## Sobre o projeto

O portfólio funciona como uma apresentação profissional, reunindo informações sobre minha formação, tecnologias que estudo e projetos que desenvolvi durante minha jornada na programação.

A interface foi construída com uma navegação por seções, permitindo que o visitante encontre as informações de maneira organizada e intuitiva.

## Estrutura do site

O site é dividido em seis seções principais:

### 1. Início
- Apresentação pessoal.
- Nome e área de formação.
- Breve descrição dos conhecimentos e áreas de interesse.
- Imagem de apresentação.
- Botão de contato com navegação direta para a seção de contato.

### 2. Sobre mim
- Apresentação pessoal e acadêmica.
- Descrição dos interesses na área de tecnologia.
- Informações sobre minha trajetória e objetivos profissionais.
- Botão para visualizar e acessar meu currículo em PDF.

### 3. Informações
Área dedicada a informações pessoais e acadêmicas:
- E-mail para contato.
- Formação em Engenharia de Software.
- Localização: Brasília - DF.
- Idiomas: inglês fluente e espanhol avançado.

### 4. Ferramentas e tecnologias
Seção visual com as principais tecnologias e ferramentas que utilizo ou estudo:

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Python
- Linguagem C
- MySQL
- Git

### 5. Projetos
Apresentação dos projetos desenvolvidos, organizados em cards com imagens, descrições, tecnologias utilizadas e links para os respectivos repositórios no GitHub.

**Landing Page — Altavilla Advocacia**
- Landing page institucional de um escritório de advocacia fictício.
- Interface desenvolvida para apresentar serviços jurídicos.
- Navegação entre seções e apresentação das informações do escritório.
- Tecnologias: HTML, CSS e JavaScript.

**Sistema Bancário em Python**
- Simulação de uma conta bancária por meio de um menu interativo no terminal.
- Criação de senha e sistema de login.
- Consulta de saldo.
- Operações de depósito e saque.
- Encerramento do sistema.
- Tecnologia: Python.

**Projetos acadêmicos em C**
- Coleção de exercícios desenvolvidos durante os estudos da linguagem C.
- Exercícios de lógica de programação.
- Estruturas condicionais.
- Laços de repetição.
- Funções e outros conceitos de programação.
- Tecnologia: C.

**Banco de Dados Acadêmico**
- Projeto de modelagem e implementação de um banco de dados para gestão acadêmica.
- Estrutura composta por 10 tabelas.
- Relacionamentos entre alunos, professores, cursos, turmas e disciplinas.
- Scripts SQL para criação e inserção de dados.
- Tecnologias: MySQL e MySQL Workbench.

### 6. Contato
Seção destinada à comunicação e apresentação de oportunidades profissionais.

- Botão para envio de e-mail.
- Link para o GitHub.
- Link para o LinkedIn.
- Apresentação de disponibilidade para estágios, projetos e novas oportunidades.

### Rodapé
Identificação do desenvolvedor e ano de desenvolvimento.

## Como executar localmente

1. Clone o repositório:

```bash
git clone https://github.com/vinirodrigues-hub/vinirodrigues-portfolio.git
```

2. Entre na pasta do projeto:

```bash
cd vinirodrigues-portfolio
```

3. Abra a pasta no Visual Studio Code ou em outro editor de código.

4. Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão Live Server no VS Code para visualizar as alterações durante o desenvolvimento.

**Observação:** mantenha a estrutura de pastas original para garantir o carregamento correto dos arquivos CSS, JavaScript, imagens e demais recursos.
